# APacks Rewards Research

Fictional R + Quarto portfolio case study using synthetic data.

This version gives each of the five rewards its own diagnostic story:
- DineLocal — scale & replicate
- StreamPlus — fix / retarget
- MoveNow — continue / monitor
- FitLife — improve & retest
- FoodDrop — rethink

Open `apacks-rewards-case-study.Rproj`, then `index.qmd`, and click **Render**.
The rendered site goes to `docs/` for easy GitHub Pages hosting.

All companies, respondents, comments, results and generated visuals are fictional/synthetic.
